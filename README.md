# Mega Costruzioni Srl — sito demo

Proposta di sito per Mega Costruzioni Srl (Caserta): lavori condominiali e piscine.

- `index.html` — pagina unica (hero, servizi condominiali, metodo, piscine con modello 3D interattivo, lavori, recensioni, preventivo via WhatsApp, area servita), stile e script
- `img/` — foto illustrative Pexels (licenza libera): non ritraggono lavori dell'impresa
- Modello 3D della piscina con Three.js r128 (cdnjs); se WebGL non è disponibile compare una foto

Sito statico, nessuna build. Pubblicato con GitHub Pages. Demo non indicizzata (`noindex`).

Da confermare con il titolare: indirizzo della sede, P.IVA, elenco servizi, comuni serviti, foto reali dei cantieri, testi delle recensioni (con consenso), informativa privacy e cookie.
